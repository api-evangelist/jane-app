- [Get a Patient](https://developers.jane.app/reference/getpatient-1.md): Retrieve detailed patient information using their unique identifier
- [Get a list of patients](https://developers.jane.app/reference/getpatients-1.md): Retrieve a list of patients.  Filtering: Filter records by field values using the format: field[operator]=value  Available fields: - `public_id`: string - `created_at`: ISO 8601 datetime (e.g. 2025-01-01T12:00:00Z) - `updated_at`: ISO 8601 datetime  Available operators: - `eq`: Equals - `gt`: Greater than - `gte`: Greater than or equal - `lt`: Less than - `lte`: Less than or equal  Date-time filters (ex. `created_at`, `updated_at`) must: - Use [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601) date-time format - Be **precise to the second** (e.g. `2025-01-01T12:00:00Z`)  Free-text search across name, email, phone, and patient number is available via `POST /patients/search` (PII is not supported in query strings).  Examples: ``` /patients?public_id[eq]=abc123 /patients?created_at[gte]=2025-01-01T00:00:00Z&created_at[lt]=2025-01-02T00:00:00Z ```
- [Search patients by free text](https://developers.jane.app/reference/searchpatients.md): Free-text patient search across name, email, phone number, and patient number.  This is a POST-body endpoint specifically so PII (patient names, email, phone) does not leak into URL query strings, access logs, browser history, or referrer headers.  Scope is intentionally search-only: the body accepts `search`, `sort`, and `page`. Structured filters (`public_id`, `created_at`, `updated_at`) are not supported here — use `GET /patients` for those. Combined search + structured filtering is a deliberate follow-up if a consumer need materializes.  Filter operators: - `search`: `co` (contains) only  Pagination: the response returns a `cursor` and `hasNextPage`. To fetch subsequent pages, re-POST the same body with `page.cursor` set to the previous response's `cursor`. The `links` object is omitted from this endpoint's response (GET-style pagination URLs would re-expose filter PII in query strings).  Example body: ```json {   "search": { "co": "Jane Smith" },   "sort": "-created_at",   "page": { "limit": 50 } } ```
